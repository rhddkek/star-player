# 유명 축구 게임 벤치마크 → 스타 플레이어 개선안

작성 2026-11-06 · 대상: EA SPORTS FC 27 / eFootball 2026 / Football Manager / New Star Soccer / Mini Soccer Star / 이나즈마 일레븐·캡틴 츠바사 / 벤치에서 발롱까지

> 한 줄 결론: 우리 게임의 차별점은 「한 명을 직접 뛰는 손맛」이다. 그래서 가져올 것도 **경기 AI와 조작 감각** 위주로 고르고, 메타(커리어·공유)는 유행 게임의 「짧게 자랑하기」만 빌린다.

## 1. 경기 AI — 가져올 기술 (우선순위 순)

각 항목: **그들의 방식 → 우리 현재 → 적용안 → 측정 방법**

### 1-1. 동료 AI에 「성향」 부여 (eFootball 플레잉 스타일 / FC 플레이스타일) ★★★
- **그들:** 같은 포지션이라도 선수마다 다르게 움직인다. 윙어가 「인사이시브 런」이면 안으로 꺾고, 「얼리 크로서」면 일찍 올린다. FW가 「스피딩 불릿」이면 공간 보이면 바로 뒤로 뛴다.
- **우리:** 동료는 `subRole`(CB/FB/DM/CM/WM/WF/ST)로만 움직여 모두 똑같다. 같은 팀 윙어 둘이 같은 결정을 한다.
- **적용안:** 선수 생성 시 `pl.style` 1개 부여 (클럽 전력·포지션별 가중 추첨). 8종이면 충분:
  - `cutIn` 안으로 꺾는 윙어 — 측면에서 공 잡으면 중앙으로 드리블, 슛 선호
  - `earlyX` 얼리 크로서 — 하프라인 넘으면 바로 크로스
  - `runner` 스피딩 불릿 — 수비 뒷공간으로 침투 요청 빈도 2배 (내가 공 잡으면 바로 달린다 → 스루 패스 손맛)
  - `target` 타깃맨 — 내려와서 등지고 받기, 헤더 선호, 원투 벽 역할
  - `playmaker` 레지스타 — 뒤에서 롱패스·전환 패스
  - `b2b` 박스투박스 — 공격 땐 박스 안까지, 수비 땐 끝까지 복귀
  - `invWB` 인버티드 윙백 — 공격 시 안쪽으로 (FM) — 이미 `isWB` 일부 구현
  - `wall` 스토퍼 — 앞으로 나가서 끊는 CB vs `sweeper` 뒤를 지키는 CB
- **효과:** 같은 전술이라도 팀마다 경기가 달라진다. 이적 결정에도 쓸 수 있다(「이 팀 윙어는 침투형이라 내 스루패스가 산다」).
- **측정:** h93 하네스에 성향별 행동 횟수(컷인·얼리 크로스·침투) 집계, 팀 간 분산이 생기는지.

### 1-2. 패스 후 곡선 침투 (FC 27 「Pass & Follow Run」) ★★★
- **그들:** 패스한 선수가 서 있지 않고 **곡선**으로 빈 공간에 뛰어든다. AI가 오버랩/언더랩을 골라 뛴다.
- **우리:** 원투(give-and-go)는 있지만 직선 돌파다. 동료가 패스한 뒤 멈추는 경우가 많다.
- **적용안:** `passTo` 직후 패서에게 `pl.followT=2.0` 부여. 목표점은 수비수 사이 빈 곳(`bestSupport`의 공간 점수 재사용)으로 **베지어 곡선**(바깥→안쪽)을 따라 이동. 내 선수가 패스한 경우엔 `runSpot`을 곡선 끝점으로 표시해 「침투 위치 안내」와 연결.
- **측정:** h92 `optAvg`(내 패스 옵션 수) 상승, 원투 성공률.

### 1-3. 수비 — 「사람이 결정, AI는 모양 유지」 (FC 27 방향) ★★★
- **그들:** FC 27은 AI 자동 태클·컨테인을 줄이고 마킹 거리를 늘렸다. 이유: 자동 수비가 너무 똑똑하면 사람이 할 게 없고, 너무 공격적이면 우르르 몰린다.
- **우리:** 방금(v59) 압박 1~2명으로 제한. 방향은 같다. 부족한 것은 **조키(jockey)** — 태클 안 하고 거리 유지하며 패스길 막기.
- **적용안:**
  1. 첫 번째 압박자는 공 소유자 2.2m 앞에서 **조키**(태클 안 함, 상대 드리블 방향으로 같이 이동, 상대가 공을 1.3m 이상 흘리면 그때 태클). 지금은 바로 달려들어 제쳐진다.
  2. 나머지는 **블록 유지 + 패스길**(laneBlock) — 이미 있음. 라인 간격을 FM처럼 전술별 수치화: `press` 좁게(DF-MF 12m) / `counter` 깊고 넓게(18m).
  3. **세컨드맨 프레스 버튼(내 선수가 수비할 때):** FIFA의 R1 처럼 「동료 압박」을 내가 누르는 순간에만 2번째 압박자가 붙는다 → 수비도 조작이 된다. 지금은 `userHelps` 자동 판정.
- **측정:** h95 `swarm4`(8m 안 4명 이상) 5% 이하 유지, 상대 드리블 돌파 성공률 하락, 태클 성공률.

### 1-4. 골키퍼 — 스위퍼 키퍼 · 1:1 좁히기 · 배급 선택 ★★
- **그들:** 1:1에서 키퍼가 **나와서 각을 좁힌다**(FIFA 「rush」 수동/자동). 뒷공간 긴 패스는 박스 밖까지 나와 처리. 잡은 뒤 빠른 스로/느린 빌드업을 상황별로.
- **우리:** v59에서 캐치·안고 있기 추가. 1:1 좁히기는 `rushing` 플래그만 있고 거리 판단이 단순. 배급은 거의 롤.
- **적용안:**
  - 1:1: 공격수가 박스 안 단독 돌파면 키퍼가 **공과 골문 중간 60% 지점**까지 전진해 슛 각 축소(슛 성공률 −25%) — 대신 칩슛(이미 스킬 있음)이 통한다 → 손맛 포인트.
  - 뒷공간 롱볼: 수비 라인 뒤로 떨어지는 공은 키퍼가 먼저 도달 가능하면 박스 밖까지 나가 걷어냄(슬라이딩 X, 발로).
  - 배급: 상대가 압박 중이면 가까운 풀백 스로, 상대가 내려가 있으면 빠른 역습 롱킥(우리 ST `runner` 성향에게).
- **측정:** h95 `gkCatchPM` 유지, 1:1 득점률(현재 미측정 → 추가), 뒷공간 패스 성공률.

### 1-5. 세트피스 — 2단계 코너 · 벽 조작 ★★
- **그들(FC 27):** 코너 = ①어디로 얼마나 세게 ②달려들어 타이밍 맞춰 헤더(수동 컨택). 수비는 벽·마크 자리 조정.
- **우리:** 코너·프리킥 자동 or 단순 킥. 헤더 모션은 있음.
- **적용안:** 코너킥 때 내 선수가 키커가 아니면 **박스 안 침투 미니 조작**: 2초 동안 조이스틱으로 자리 잡고, 공이 떨어지는 순간 슛 버튼 = 헤더 타이밍(⚡게이지). 프리킥은 내가 키커일 때 커브 게이지(좌우 드래그).
- **효과:** 지금 「기다리는 시간」인 세트피스가 손맛 구간이 된다.

### 1-6. 드리블 — 몸싸움·오프밸런스·실드 ★★
- **그들:** FC 27 오프밸런스: 부딪혀도 능력치 높으면 공 안 잃고 비틀거리며 진행. eFootball: 등지고 버티기(실드)가 강력.
- **우리:** 태클 당하면 바로 뺏김/파울. 보호 시간(`protT`)만 있음.
- **적용안:**
  - 어깨 싸움: 상대가 옆에서 붙으면 `balance=(str+agi)/2` 비교 → 이기면 **휘청(off-balance 0.4초)** 하되 공 유지, 지면 공이 1.5m 튕겨 나감. 애니메이션은 `trap` 프레임 재활용 + 좌우 흔들림.
  - 실드 버튼(달리기 길게 누르기 = 등지고 버티기): 속도 0, 태클 저항 +40%, 원투 벽 역할.
- **측정:** 드리블 돌파 성공률 (현재 미측정), 파울 수.

### 1-7. 체력이 후반 공간을 만든다 (FIFA 스태미나 곡선) ★
- **그들:** 후반 70분 이후 압박 거리·복귀 속도가 떨어져 공간이 열린다 → 교체 의미, 후반 역전 드라마.
- **우리:** 내 선수 `M.sta`만 있고 동료·상대는 무한 체력.
- **적용안:** 모든 선수 `pl.sta` (0~1). 압박·전력 질주마다 소모. 0.5 이하면 최고 속도 −12%, 압박 참여 거리 −30%. 전술 `press`는 소모 1.4배 → **압박 전술의 대가**가 생긴다. 하프타임 지시 「지금처럼」이 체력 회복 +15%로 의미가 커진다.
- **측정:** 후반 75분+ 득점 비율 (실축 ~25%)을 시뮬로 확인.

### 1-8. 콤비 플레이 발동 (eFootball Link-Up Play → 우리 「호흡」 시스템 확장) ★
- **그들:** 특정 감독+특정 두 선수 조건이 맞으면 정해진 콤비 플레이(대각 롱패스 등)가 발동.
- **우리:** 단짝(buddy) 호흡·콤보 수가 이미 있다. 호흡이 올라가도 「경기 안」에서 눈에 띄는 변화가 적다.
- **적용안:** 호흡 단계별 **콤비 기술 해금**: 호흡 30 「원투 자동 벽」(단짝이 내 패스를 받으면 항상 바로 돌려줌·컷인 표시) → 60 「텔레파시 스루」(단짝이 침투 시작하면 화면에 황금 화살표, 스루 성공률 +20%) → 90 「세트 플레이」(코너 때 단짝 숏코너 → 컷백 패턴). 이나즈마의 「합체 필살기」를 리얼하게 번역한 것.

### 1-9. 심판·판정 디테일 ★
- 어드밴티지(파울 당해도 공 유지하면 진행, 「어드밴티지!」 자막 — 중계 자막 시스템 재사용), 부상 시간 누적이 실제 추가시간에 반영, VAR는 **골 취소 연출**(오프사이드 골 1초 뒤 「VAR 확인 중…」→ 취소)만 가끔. 세리머니 중 상대 선수 반응.

## 3. 커리어·메타 (FM · NSS · 유행 웹게임)

1. **감독 지시 → 경기 목표 (FC 플레이어 커리어)** — 이미 REQS 있음. 보완: 목표가 포지션·성향별로 달라지고, 달성 시 **감독 신뢰 + 특정 스탯 보너스** 같이. 미달 3회면 벤치 경고.
2. **경기 밖 이야기 (NSS)** — 주 1회 짧은 이벤트 카드(선택지 2개): 기자 인터뷰(명성↑/감독 신뢰↓), 라이벌 도발(다음 맞대결 보정), 단짝 생일, 팬 사인회(컨디션↓ 명성↑), 에이전트 제안. 결과는 1줄. 「벤치에서 발롱까지」가 이것만으로 폰을 못 놓게 만들었다.
3. **라이벌 선수 (이나즈마·NSS)** — 같은 포지션 경쟁자/상대팀 에이스를 시즌 라이벌로 고정. 맞대결 전 라이벌 카드, 승패 기록, 라이벌이 이적하면 소식.
4. **은퇴 카드 + 일일 랭킹 (벤치에서 발롱까지)** — 통산 기록·우승·발롱도르를 한 장 이미지로(캔버스 → PNG 저장/공유). 랭킹은 아티팩트 버전의 공유 저장소로, GitHub 버전은 로컬 명예의 전당만.
5. **플레이 스타일 성장 (FC)** — 스탯이 일정치 넘으면 플레이스타일(특성) 자동 해금 제안 — 우리 TRAITS를 「선택」에서 「달성」으로. 예: 스루 패스 50회 성공 → 「킬러 패스」 특성 해금 팝업(스킬 해금 팝업 재사용).

## 4. 그들의 아쉬운 점 → 우리가 지킬 원칙

- **스크립팅 의심 금지:** FIFA 모멘텀 논란의 교훈. 흐름 바(v61)는 **표시만**, 판정에는 절대 안 섞는다. 보정이 있으면 화면에 이유를 쓴다(「홈 어드밴티지 +3%」).
- **AI가 대신 다 하지 않기:** 자동 수비·자동 슛이 너무 좋으면 내가 할 게 없다. 동료 AI 득점 비중 45%는 유지하되, 「내가 만든 찬스」 표시로 체감.
- **패스 어시스트 과잉 금지:** eFootball처럼 아무 데나 눌러도 가면 손맛이 죽는다. 조이스틱 방향 ±35° 안에서만 대상 선택(현재 유지).
- **에너지·가챠 없음:** 수익이 필요해지면 Mini Soccer Star식 「광고 보고 2배」가 아니라 **꾸미기·시즌 패스** 쪽.
- **세트피스로 시간 끌지 않기:** 2단계 코너는 3초 안에 끝나게.
- **글 줄이기:** FM처럼 숫자 벽 금지. 이미 진행 중인 원칙 유지(상태 → 행동 → 변화).

## 5. 로드맵 제안

| 단계 | 내용 | 기대 효과 | 측정 |
|---|---|---|---|
| **1 (손맛)** | 1-1 성향 8종, 1-2 패스 후 곡선 침투, 1-3 조키·세컨드맨 프레스 버튼 | 경기마다 다른 느낌, 수비도 조작 | h93/h95 지표, 내 패스 옵션 수 |
| **2 (장면)** | 1-4 키퍼 1:1·스위퍼, 1-5 2단계 코너·프리킥 커브, 1-6 몸싸움·실드, 슛 퍼펙트 타이밍 | 「와」 하는 장면 증가 | 1:1 득점률, 세트피스 득점률, 돌파 성공률 |
| **3 (드라마)** | 1-7 전원 체력, 1-8 호흡 콤비 기술, 라이벌, 주간 이벤트 카드 | 후반 역전·서사 | 75분+ 득점 비율, 세션당 플레이 시간 |

각 단계는 지금 하는 방식 그대로(시뮬 하네스로 전후 비교 → regress 추가 → 배포) 진행하면 단계당 한 회차 분량.
