# New Star Soccer(2012, v4.22) 심층 분석 — 「스타 플레이어」에 가져올 것

작성 2026-11-05. 광우가 준 APK를 풀어서 (1) 게임 안 문구 파일 13개 언어 × 3,340줄, (2) 데이터 파일(클럽 3,421개·97개국·255개 리그, 대회 규정, 조정값 2,885줄), (3) 코드 디컴파일(androguard, Monkey X → Java 2,766 클래스)로 **실제 공식과 수치**까지 읽었습니다. 그림·소리·문구는 복사하지 않았고 규칙만 정리했습니다. 규칙(아이디어)은 저작권 대상이 아니지만, 이름·문구·그림은 우리 것으로 새로 만들어야 합니다.

## 1. 한 문장 요약

**경기는 "찬스 장면 몇 번"만 직접 차고, 나머지 시간은 에너지 100을 어디에 쓸지(훈련 / 관계 / 경기) 고르는 자원 관리 게임.** 모든 시스템이 에너지와 관계 5개(감독·팀·팬·스폰서·여자친구)로 연결되어 있고, 관계가 경기 찬스 수·선발·계약·스폰서를 결정합니다.

```
                 ┌──────────── 에너지 100 ────────────┐
                 │  회복: 하루 8.5 × 나이계수(0.5~1.0)  │
                 │        + 집(최대 +30) + 트레이너(5/15/30)│
                 └──┬──────────────┬──────────────┬────┘
                    ▼              ▼              ▼
              훈련 미니게임     관계 활동       경기 (−0.75/분 ≈ −68)
              −(40+나이−20)    (요청 수락 −%)    활동량 高면 ×1.5
                    │              │              │
                    ▼              ▼              ▼
              능력치 5종       관계 5종 ◄──── 경기 평점(1~10)
              (레벨×별)         │  │             │
                    │           │  │             ▼
                    │           │  └──► 찬스 수 · 선발 · 야유 · 스폰서
                    │           ▼
                    └──► 스타 등급(0~100 × 레벨) ──► 주급·이적 가능 클럽·NRG 가격
```

## 2. 경기 — "찬스 장면" 시스템 (코드 `TMatch.SetUpChances`)

90분(+30분 연장)을 1분 단위 배열로 두고, 내가 직접 차는 장면(찬스)을 미리 심어 둡니다.

| 찬스 | 조건 | 수 |
|---|---|---|
| 기본 보장 | 0~44분 1개, 45~89분 1개, 90분 이후 1개 | 3 |
| 팀 관계 보너스 | `팀 관계 ÷ 14` 개를 0~89분에 추가 (관계 70이면 +5) | 0~7 |
| 후반 추가 | 팀 관계 > 난수(100) 이면 90분 이후 +1, 두 번 굴림 | 0~2 |
| 동정 찬스 | 팀 관계 < 50 이면 +1 (초보 구제) | 0~1 |
| 주장 | 주장이면 +1 | 0~1 |
| 교체 투입 | 79~89분에 +1 | 0~1 |
| 마지막 찬스 | 확률(조정값)로 79~89분에 "결정적 찬스" 1개 | 0~1 |

→ **팀 관계가 곧 출전 시간의 체감**입니다. 관계 20이면 경기당 4~5번, 관계 90이면 10~12번 공을 만집니다.

**찬스 종류**는 집중(공격/균형/수비)에 따라 뽑습니다. 공격 집중은 슛·드리블이 많고, 수비 집중은 가로채기(인터셉트)가 많습니다. 시야(VISION) 능력치가 높을수록 찬스 장면에 패스 받을 동료가 더 많이 등장합니다(60~70 난수와 비교).

**평점(1~10)** 은 찬스마다 행동 결과로 가감합니다(조정값):

| 행동 | 성공 | 실패 |
|---|---|---|
| 짧은 패스 | +0.5 | **−2.0** |
| 긴 패스 | +1.0 | −2.0 |
| 마무리 슛 | +1.5 | −1.5 |
| 중거리 슛 | +1.5 | −1.5 |
| 크로스·헤딩·수비·세트피스 | +1.0 | −1.0 |
| 드리블 | +1.0 | −1.5 |

→ 짧은 패스 실패가 가장 비쌉니다. "쉬운 걸 틀리면 크게 깎인다"는 설계.

**에너지 소모:** 1분마다 0.75 (활동량 가볍게 ×0.5, 세게 ×1.5), 24세부터 나이당 +0.01. 하프타임 +5, 90분 +3, 105분 +2. 에너지가 바닥나면 "지쳐서 교체"됩니다. 즉 **풀타임 뛰면 68 정도가 빠지므로, 경기 전에 에너지 50 이상을 남겨 두는 게 매주의 과제**입니다.

**팬 야유:** 출전 10경기 이상인데 골·도움 없고 패스 5개 이하, 활동량 낮고, 찬스 중 패스보다 허비가 많으면 야유가 터지고 공을 뺏깁니다(팬 관계가 난수 −25~60보다 낮을 때).

**재시도:** 찬스를 망치면 "다시 하기"를 돈(Bux)으로 삽니다. 1회 10, 횟수마다 10→100까지 상승. (수익화 포인트)

## 3. 경기 후 — 관계·스타 등급이 움직이는 공식 (`TScreen_MatchStats`)

```
감독 Δ = 평점 − 5           (평점 ≤ 5 이면 −(6−평점))
팀   Δ = (패스 − 2) + 도움×2 − (찬스 − 패스 − 슛…)   ← "공을 혼자 끌면 팀이 싫어함"
팬   Δ = 이겼으면 +(평점−5), 졌으면 −(6−평점) −1 (원정 −2)
      비겼을 때 약팀 상대면 −1, 강팀 상대면 +1
활동량 평균이 "가볍게"였으면 셋 다 −1
스타 레벨 1 이면 셋 다 +1 (초보 보정), 레벨 4 이상이면 셋 다 −1 (높을수록 기대치 ↑)
골+도움 ≥ 3 또는 팀 득점만큼 혼자 넣었으면 음수 금지
최종 −5 ~ +4 로 클램프 (하드모드 −10 ~ +4, 추가 −1)
스타 등급 += 감독Δ + 팀Δ + 팬Δ  (+ 인터뷰 성공 시 +10)
```

**인터뷰 미니게임**(초록 버튼 순서 외우기, 9~15개 버튼)을 실패하면 이 경기에서 얻은 관계·스타 등급 보너스가 **전부 취소**됩니다. 성공하면 스타 등급 +10. 경기 후 긴장감을 한 번 더 주는 장치.

**스타 등급 = 0~100이 차면 레벨 +1.** 레벨이 주급·스폰서 수·NRG 가격·이적 가능 클럽·에이전트 가격의 기준입니다.

## 4. 선발 조건 (`GSPlayerUpdateSelectionStatus`)

클럽 경기 기준, 순서대로 검사해서 첫 번째 걸리는 이유를 보여 줍니다.

| 순서 | 조건 | 결과 메시지 |
|---|---|---|
| 1 | 감독 관계 < 10 | 명단 제외 "관계가 낮다" |
| 2 | 에너지 < 25 | 명단 제외 "에너지가 너무 낮다, 감독이 격노" |
| 3 | 폼(최근 평점 평균) < 3.5 이고 최근 2경기 5점 미만 | 명단 제외 "폼이 나쁘다" |
| 4 | 감독 관계 < 40 | 벤치(교체) |
| 5 | 에너지 < 50 | 벤치 |
| — | 통과 | 선발 |

국가대표는 감독(국대) 관계 50/65, 에너지 25/50으로 더 엄격. 벤치로 시작하면 국대 감독 관계 −7.5, 명단 제외는 −15.

→ 우리 게임의 감독 신뢰(60 선발, 45 벤치)와 같은 구조인데, NSS는 **에너지도 선발 조건**이라는 점이 다릅니다. 에너지를 훈련에 다 써 버리면 벤치로 밀립니다.

## 5. 능력치와 훈련 (`TMatch.SetUpTraining / TrainingSuccess`)

- 능력치 5개(파워·속도·기술·시야·프리킥), 각각 **100레벨 × 레벨당 별 0~3**. 능력치 값 = 별의 합(최대 100 캡).
- 훈련 = 킥 미니게임 1판, 목숨 3개. 남은 목숨이 그 레벨의 별이 됩니다(한 번에 성공 = 별 3). 실패하면 다음 레벨이 안 열립니다.
- **훈련 1판 에너지 = 40 + max(0, 나이−20)** (하드모드 +5), 트레이너가 있으면 감소. 하루 최대 3번. → 20세면 2판 하면 경기 에너지가 모자랍니다.
- **능력치 감소:** 마지막 훈련 뒤 `(16 − 연차/2)주`(최소 2주)가 지나면 그 능력치의 최고 레벨 별이 0으로. 트레이너가 미리 경고. 1년차는 감소 없음.
- 나이 = 16 + 연차. 에너지 회복 계수가 22세부터 0.9 → 27세 0.8 → 32세 0.7 → 37세 0.6 → 42세 0.5.
- **연습장(Practice):** 에너지 5로 아케이드식 슛 연습. 10/15/20/25/30골 넘기면 보상(돈, 감독·팀·팬·스폰서 관계 +3 중 하나, 스폰서 제안).
- 생활 이벤트 중 "사고"(체육관에서 삐끗, 클럽에서 과음 등 12장소 × 5문구)가 28일에 한 번꼴 확률로 터져 능력치 1~3레벨이 깎입니다(23세까지 1, 32세까지 2, 그 이상 3).

**플레이 성향 칭호 18종**(`playerdesc_*`): 찬스 행동별 성공 집계(`m_ratings[10]`)로 "골 사냥꾼·롱패서·윙어·공중볼 장인·데드볼 스페셜리스트·플레이메이커·클래식 10번…"을 자동 부여. 최고치면 "천재/마스터".

## 6. 관계 5종 + 행복도

| 관계 | 오르는 법 | 떨어지는 법 | 쓰임 |
|---|---|---|---|
| 감독 | 평점, 훈련·연습 보상, 감독 요청 수락(에너지 −%) | 낮은 평점, 재계약 거절, 도박 적발(−20%), 여자친구 스캔들 | 선발/벤치, 재계약 가능 여부 |
| 팀 | 패스·도움, 팀 요청(골프·카트·포커·자선), 짝 맞추기 +5 | 공 혼자 끌기, 쇼핑·카지노 안 가면 −5, 이적 소문 −10% | **찬스 수**, 패스 요청 반응 |
| 팬 | 승리+평점, 팬 요청(사인회·고장난 차 돕기), 연습 | 패배, 활동량 낮음, 도박 적발(어리면 −90%) | 야유→공 뺏김, 스폰서 조건 |
| 스폰서 | 요청(광고 촬영·행사), 연습 | **경기마다 스폰서 수 × 0.65 자동 감소** | 20 밑이면 계약 해지(해지되면 +30 반동) |
| 여자친구 | 선물·데이트 선택 | 방치, 스캔들 | 행복도에 2배 가중, 에너지 보너스 이벤트 |

행복도 = (감독 + 팀 + 팬 + 여자친구×2 + 스폰서) ÷ 6. 행복도가 낮으면 뉴스 기사와 능력 저하 이벤트.

**딜레마(주 1회꼴, 라운드 3배수):** 관계 2개가 무작위로 뽑혀(스폰서 있으면 팬 자리에 스폰서 가능) "A를 고르면 A↑, 안 고른 B는 −10". 선택 뒤 장소 사고 확률.

**요청 메시지:** 감독 5·팀 5·팬 5·스폰서 10종. 전부 "에너지 N% 쓰고 관계 올릴래?" 형식. 거절하면 관계 손해. → 에너지가 모든 선택의 공통 화폐.

**짝 맞추기 카드**(Pairs): 관계 하나 골라 성공하면 +5. 하루 관계 활동 최대 3번.

## 7. 돈·계약·스폰서·생활

- 화폐 1종(Bux). 시작 15. **주급 = 스타 레벨 + 능력치 합(%)×레벨** (레벨 1이면 경기당 1~2). 골 보너스 = 레벨/4+1, 도움 보너스 = 레벨/5. 레벨 60에서 캡.
- 재계약 협상 = "다음 카드가 높을까 낮을까" 5연속 맞히기. 3턴째부터 주급 +1, 5턴 +2. 틀리면 그 전 턴까지 수락 가능. 감독 관계·팬 관계가 낮으면 협상 자체를 거부, 같은 클럽 재협상은 쿨다운.
- 이적: 시즌 절반 지점에서 이적창 28일. 84일 간격. 후보 클럽 = 전력 > (스타등급+200)/10 이면서 현 클럽 전력+10 이하(가끔 그 이상). 먼저 "루머" 뉴스 → 이후 매주 50% 확률로 오퍼. 창 닫힐 때 팀 관계 60 이상이면 −10%, 아니면 +20%.
- 스폰서 10업종(축구화·차·옷·화장품·전자·음식·보석·스포츠웨어·음료·시계). 스타 레벨 N이면 N개까지. **10경기마다** 검사: 라이프스타일 ≥ (스폰서수−2)×10, 팬 관계 ≥ 같은 값 이어야 새 제안. 경기당 수입 = 업종번호/2+1.
- 에이전트/트레이너: 가격 = 레벨×5+25, 기간제. 에이전트 주급 +10/20/30%, 트레이너 회복 +5/15/30 & 훈련 비용 감소 & 능력치 감소 경고. (광고 시청으로 무료 체험)
- 생활 아이템 20종·집 6·차 6. 라이프스타일 % = 보유 수 ÷ 전체. 매 경기 **마모 +0.9~1.4%씩(아이템 순서대로 가속)**, 수리비 발생. 집 수가 에너지 회복 +(30 × 집/전체).
- NRG 음료: 가격 = 레벨×3/5/7/25(−1). 에너지 100% 회복 + 능력치/관계 +1. 레벨 80에서 가격 캡.
- 카지노(블랙잭·룰렛·슬롯)·경마: 18세 미만 적발 시 감독 −75%·팬 −90%, 성인도 −20%. 팀원들이 같이 가자는데 안 가면 팀 −5.
- 뇌물 이벤트: 일부러 지면 돈, 적발 시 스캔들.

## 9. 설계 해석 — 왜 재미있었나

1. **에너지가 단일 통화.** 훈련·관계·경기가 전부 같은 에너지를 두고 다투니 매주 "무엇을 포기할까"가 생깁니다. 선발 조건에 에너지가 들어가서 과훈련도 벌을 받습니다.
2. **관계가 숫자가 아니라 경기에서 보입니다.** 팀 관계 → 찬스 수, 팬 관계 → 야유로 공을 뺏김, 감독 관계 → 벤치. 메뉴 숫자가 경기 체감으로 돌아옵니다.
3. **경기 후 확인 절차가 두 겹.** 평점 → 관계 Δ 계산 → 인터뷰 미니게임 성공해야 확정. 실패하면 전부 무효. 짧지만 긴장이 생깁니다.
4. **안 하면 깎인다.** 능력치 16주 미훈련 감소, 스폰서 관계 경기마다 자동 감소, 아이템 마모. 유지 비용이 있어서 돈과 에너지가 계속 필요합니다.
5. **초보 보정이 코드에 박혀 있습니다.** 팀 관계 50 미만이면 찬스 +1, 스타 레벨 1이면 관계 Δ +1, 1년차 능력 감소 없음, 데뷔 2경기는 쉬운 찬스.
6. **수익화 지점이 전부 "시간을 산다"입니다.** 찬스 재시도, NRG, 에이전트·트레이너 체험(광고), 능력치 부스트 음료.

약점(우리가 피할 것): 경기 자체가 얕아서 10시즌쯤 지나면 반복 피로, 여자친구·도박·뇌물은 등급 심사 리스크, 숫자가 많아 초보가 인과를 못 느낌(그래서 도움말 88개).

## 11. 이식 제안 (수치까지)

우선순위 순. 각 항목에 NSS 수치를 우리 단위로 옮겨 적었습니다.

### A. 관계 3축 (감독 신뢰는 유지, 팀 케미·팬 인기 추가)
- **팀 케미 0~100**, 시작 50. 경기 후 Δ = (패스 성공 − 4) + 도움×2 − 혼자 끈 횟수(1초 내 뺏김·과한 터치), −5~+4 클램프. 이적·임대 시 50으로 초기화.
  - 경기 체감: 패스 요청 응답 확률 = 40% + 케미×0.5%, 원투 리턴·침투 스루 빈도, 벽패스 리턴. 케미 80 이상이면 합체 필살기 해금.
- **팬 인기 0~100**, 시작 50. 이기면 +(평점−5), 지면 −(6−평점)−1(원정 −2), 비기면 상대 강약에 따라 ±1.
  - 경기 체감: 홈에서 인기 70 이상이면 기력 회복 소폭(하프타임 +10), 원정에서 인기 30 이하이고 터치 적으면 "야유" 연출 + 트래핑 시간 +30%. 스폰서 제안 조건에 팬 인기 포함.
- 기자회견 결과가 명성뿐 아니라 팀/팬 관계에도 ±3.

### B. 훈련 미니게임 + 별 + 미훈련 감소
- 주간 훈련 선택 → 20초 미니게임(슛: 과녁 3개 / 패스: 움직이는 동료 / 드리블: 콘 지그재그 / 태클: 타이밍 / 체력: 연타 리듬). 목숨 3개, 남은 목숨 = 별. 별 3 = +1 확정, 별 2 = 70%, 별 1 = 40%, 실패 = 0 (현재 성공률 78% 체계와 호환).
- 컨디션 비용은 지금(−12) 유지. 대신 **6주 미훈련 시 그 능력치 −1** (NSS는 16주이지만 우리는 라운드가 짧으니 6). 홈에 "마지막 훈련: 3주 전" 표시, 5주째 경고.

### C. 선발 조건에 컨디션 추가
- 컨디션 < 35 이면 벤치, < 20 이면 명단 제외(감독 신뢰 −3). 홈 다음 경기 카드에 이유 한 줄. 이러면 "광고 촬영·훈련으로 컨디션 다 쓰기"에 대가가 생깁니다.

### D. 주간 선택 이벤트(딜레마) + 요청 메시지
- 라운드 3배수마다 1개: 두 관계가 뽑혀 "팀 회식 vs 팬 사인회". 고른 쪽 +8, 안 고른 쪽 −5(NSS −10은 과함). 10%로 소소한 사고(컨디션 −10).
- 요청 메시지: "감독이 유소년 코칭 부탁(컨디션 −10, 신뢰 +6)", "동료 골프(컨디션 −8, 케미 +6)", "팬 사인회(컨디션 −6, 인기 +6)", "스폰서 촬영(컨디션 −8, 돈 +, 명성 +)". 거절 시 −2.

### E. 유지 압박
- 스폰서 관계 대신 우리는 **광고 KPI**가 있으니, 추가로 "스폰서 만족도"가 경기마다 −1, 요청 수락·KPI 달성으로 회복, 20 밑이면 해지 경고. 장비 내구도(이미 있음)에 생활 아이템 마모는 넣지 않음(우리 생활 아이템은 소수라 성가심만 큼).

### F. 플레이 성향 칭호
- 경기 기록 누적(골·도움·기회창출·롱패스·드리블·태클·헤딩·세트피스)으로 상위 2개 조합 → 칭호 18종 정도("택배 윙어", "박스 안의 여우", "롱패스 사령관", "공중 지배자"…). 프로필·결과 화면·시상식에 표시. 이름은 전부 새로 짓습니다.

### G. 재계약 협상 미니게임
- NSS의 높/낮 카드는 운이라 아쉬움. 우리는 **에이전트 카드 3장 중 2장 고르기**(주급·출전 보장·바이아웃·계약 기간·보너스)로 하고, 감독 신뢰·팬 인기가 낮으면 카드가 줄어드는 식이 더 맞습니다(보류 목록 ③과 합침).

### H. 넣지 않을 것
- 카지노·경마·뇌물·여자친구: 심사 등급과 분위기. 여자친구 역할(행복도·에너지 보너스)은 "가족·친구" 한 축으로 대체 가능하나 지금은 보류.
- 찬스 재시도 유료: 우리는 직접 조작이라 맞지 않음.

### 추천 작업 순서
1. A(관계 3축) + C(선발에 컨디션) — 데이터 구조와 홈 카드 한 번에
2. B(훈련 미니게임 + 감소)
3. D(딜레마·요청)
4. F(칭호) → 시상식·프로필에 연결
5. G(협상)
