# 스타 플레이어 v130 · 2시즌 전수 누르기 점검 (2026-11-14)

## 어떻게 했나
- 가로 폰 화면(852×393)에서 실제 터치로 새 커리어를 만들어 2시즌 끝(시즌 2 종료 뒤 이적 제안 화면)까지 진행. 약 30분, 터치 1,727번.
- 화면에 나온 버튼 종류 843개 중 727개는 2번 이상, 116개는 1번 누름(매주 글자가 바뀌는 버튼은 같은 종류로 못 묶인 경우 포함).
- 경기: 직접 조작(봇) 풀경기 3판 + 고교 결승 1판, 찬스 4판, 자동 8번, 5경기 진행 16번, 결장 4번. 풀경기 한 판 약 3분 30초.
- 화면 126종마다 넘침·잘림·작은 글자·작은 버튼·겹침을 자동 측정하고, 대표 화면 64장을 눈으로 확인.
- 못 한 것: 세로 화면, 시즌 2 끝 이적 결정 이후, 대표팀·월드컵, 은퇴, 저장 삭제·초기화류 버튼, 실제 손가락 조작감.

## 바로 고친 것 (v131)
1. 프롤로그 결승 준비 화면에서 「돌아가기」로 홈에 나올 수 있었고, 거기서 상대(서진고) 엠블럼을 누르면 오류 → 프롤로그에선 돌아가기를 빼고, 고교 팀은 구단 프로필을 열지 않음.
2. 주간 활동을 끝낸 뒤 창의 「홈으로 · 다음 경기」가 홈에서 열었을 땐 아무 반응 없음 → 창이 닫힘.
3. 더 싼 축구화로 바꿀 때 버튼이 「교체 구매 · -60만」 → 「교체 · 60만 돌려받음」.
4. 연습장 메뉴의 「조작 배우기」 글자가 가로 화면에서 두 줄로 깨짐 → 한 줄.
5. 프롤로그 경기 준비의 킥오프 버튼을 줄 전체로.

## 문제점 (판단이 필요해 안 고침)
1. **재계약 직후 또 계약 가능.** 시즌 끝에 원소속팀과 재계약(계약금 수령)한 뒤, 같은 여름 시장에서 남은 제안으로 바로 다른 구단과 계약할 수 있음. 실제로 재계약 → 1라운드 만에 이탈리아 3부로 이적.
2. **이적 직후 4주 연속 명단 제외.** OVR 48로 경쟁자 55~58인 팀에 가자 4라운드 동안 「경기 결과 보기」만 누름. 임대 제안이 와서 풀렸지만 그 전엔 할 일이 없음.
3. **알림 띠가 위쪽 탭 줄을 가림** (이적 거절, 장비 장착 알림 등). 뜨는 동안 탭을 못 누름.
4. **누르기 작은 버튼** (권장 높이 40 이상):
   - 능력치 + / − 35×18, 개인 코치 − / + 23×23
   - 스킬 분류 칩 38×24, 주간 훈련 능력치 칩 62×21
   - 「닫기」 43×28, ✕ 28×28
   - 성장·커리어·리그의 탭 줄 높이 24~29
5. **경기 화면 작은 글씨**: 버튼 아래 설명(꾹=등지기, ↑롱 ↔감아 등) 7~8px.
6. **글자 잘림**: 스카우트 화면 「인도네시아 1부 · 벤치 · ★4」, 개인 코치 안내문 끝.
7. **빈 중간 창**: 성장 탭의 개인 코치·특성·스타일은 큰 빈 창이 먼저 뜨고, 그 안의 버튼을 한 번 더 눌러야 실제 화면.
8. **커리어 기록**: 시즌 진행 중인데 트로피 그림과 「리그 1위」가 우승처럼 보임.
9. **스태프·생활**: 돈이 모자라면 가격 대신 「1,214만 부족」만 보여 실제 가격을 알 수 없음.
10. **리그 탭 오른쪽 「다음 경기」**: 상대 이름 앞에 빈 네모.
11. **프롤로그 경기 준비**: 윙백으로 만들면 내 표식이 FB 표식과 살짝 겹침.
12. **챌린지 선택**: 카드는 큰데 내용이 두 줄이라 빈 곳이 많음.
13. **주간 활동 창(가로)**: 세 번째 카드부터 잘려 스크롤해야 하고, 오른쪽 「활동 선택」 칸은 비어 있음.
14. **일시정지 › 조작법**: 글이 한 덩어리라 읽기 힘듦.

## 사람이 하면 편할 것
1. **주간 활동 「지난주와 같게」**: 지금은 매주 활동 선택 → 카드 → (능력치) → 적용 → 닫기로 4~5번.
2. **경기 사이 누르는 횟수 줄이기**: 결과 → 다음 경기 준비 → 활동 → 경기 시작 → 킥오프까지 약 8번. 경기 준비 화면을 건너뛰는 설정이나 「바로 킥오프」.
3. **명단 제외 주에 할 일**: 연습장 도전·추가 훈련처럼 누를 거리.
4. **알림 띠를 화면 아래쪽으로.**
5. **가격은 항상 보이고, 모자란 금액은 옆에.**
6. **빈 중간 창 없애기**: 개인 코치·스타일은 바로 실제 화면으로.
