## 개선할 점

### 1. 가로 화면 글자가 너무 작음 (가장 큼)
가로폰에서 10px 미만 글자가 화면마다 수십 개. 휴대폰에서 읽기 힘든 크기.
| 화면 | 작은 글자 수(가로폰) | 예 |
|---|---|---|
| 스카우트 | 68 | "작은 구단 · 다음 경기 관전", 관심 단계 |
| 스킬 | 30 | 선수 띠의 FW / Lv / OVR 칩(9px) |
| 스태프·생활 | 30 | 효과 설명, 고용 상태 |
| 리그 개인 기록 | 28 | 표 머리, 순위 변화 |
| 이적 | 16 | "다음 이적 목표", 남은 계약 |
| 하프타임 | 13 | 교체 안내(7~9px) |
| 입단 제안 | 13 | "바로 선발 / 주전 경쟁" 띠(9px) |
원인: 가로 화면에 한 화면으로 넣으려고 전체를 줄이는 방식. 해결: 설명 문구를 더 빼고 남는 글자는 11px 이상으로.

### 2. 누르기 작은 버튼
- 성장·커리어 위쪽 탭 줄: 높이 27px (권장 40px 이상).
- 선수 만들기: ‹ › 화살표 28×31, "뒤로" 34×21.
- 은퇴 화면(작은 가로): 탭 72×23.

### 3. 세로 화면 커리어 탭 글자 잘림
"스카우트 / 후원·광고 / 스태프·생활" 탭 글자가 칸보다 김. 세로 화면은 시안 없이 쌓은 배치라 전반적으로 한 번 더 다듬을 필요.

### 4. 첫 스킬 체험에서 빠져나오기 어려움
자동 플레이가 "화염 슛 한 번 성공하기" 연습에서 3분 넘게 성공하지 못하고 멈춤. 봇의 한계이기도 하지만, 실제로도 성공하기 전에는 화면에 나가는 버튼이 "일시정지" 안에만 있음. "나중에 하기" 버튼을 연습 띠에 두는 것을 권함.

### 5. 결과 화면 가운데 칸이 빔
골·도움이 없는 경기(0:0 등)는 가운데 칸에 결과 한 줄만 남음. 평점 한 줄 평이나 다음 경기 정보를 채우는 것을 권함.

### 6. 파일 크기 9.6MB
그림 6.4MB(2,600여 개), 소리 2.2MB. 휴대폰 첫 로딩이 느릴 수 있음. 관중 소리 5종(약 1.3MB)을 낮은 음질로 다시 뽑으면 절반 이하로 줄일 수 있음. 그림은 픽셀랩으로 교체할 때 같이 정리.

## 검사 쪽에서 고친 것
- 겨울 이적시장 검사: 제안이 1건만 와서 가끔 실패. 40회 표본은 매번 3건 정상. 검사가 고른 구단이 같은 나라면 "나라별 제안 제한"에 걸리는 것이라, 서로 다른 나라 구단을 고르도록 수정.
- 코너킥 검사: 240회 표본에서 골 8.3%, 슈팅 52%로 설계 범위(골 1~20%) 안. 40회 표본이 작아 흔들린 것이라 100회로 늘림.
- 개인 코치 검사: 창을 열 때 남아 있던 이전 창을 지우도록 게임 쪽 수정. 원인이 이것인지는 다음 전체 검사에서 확인.
- 조작 힌트 검사(라인업 중 버튼 숨김), 가로 경기 시작 검사: 각각 한 번씩 실패했으나 원인 미확인. 따로 돌리면 통과.
