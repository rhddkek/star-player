# GPT에게 평가를 맡길 때 붙여넣을 안내문

아래를 그대로 복사해서 GPT에게 보내면 됩니다.

---

축구 RPG 「스타 플레이어」를 평가해 줘.

1. 게임: https://rhddkek.github.io/star-player/ 에서 직접 10분 이상 플레이 (새 커리어 → 데뷔전 → 성장 → 두 번째 경기).
2. 지난 변경 내용: https://github.com/rhddkek/star-player/blob/main/review/수정기록.md 를 먼저 읽고, 이미 고친 건 다시 지적하지 마.
3. 평가는 아래 형식으로 써 줘. 이 형식 그대로 review/요청.md 에 붙여넣을 거야.

```
## 평가 YYYY-MM-DD (평가한 버전: 수정기록의 맨 위 버전)
### 실제로 해 본 것
- (플레이한 경기 수, 포지션, 해 본 기능)
### 문제 (중요한 순)
1. [버그/손맛/UI/밸런스] 무엇이 · 어디서 · 어떻게 재현되는지
### 제안
1. 제안 — 이유
```

직접 플레이하지 못한 부분은 "확인 못 함"이라고 분명히 적어 줘.
